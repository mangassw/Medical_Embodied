# 透析患者怎么运动更安全

## 运动的好处

- 改善体力、睡眠和情绪，帮助控制血压和体重。
- 有助于提高透析充分性和生活质量。
- 规律运动还能减少心血管并发症风险。

## 适合的运动方式

- 散步、快走、太极拳、八段锦、固定自行车等中低强度有氧运动。
- 可以从每次 10–15 分钟开始，逐渐增加到每次 20–30 分钟。
- 每周 3–5 次，以运动时能正常说话、不喘不上气为宜。

## 运动时间怎么选

- 避开透析刚结束的几小时，那时容易乏力、低血压。
- 建议在非透析日或透析后休息一段时间再运动。
- 饭后 1 小时内不要剧烈运动。

## 运动时的注意

- 内瘘侧手臂不要做大幅度的负重和拉伸动作。
- 运动前后测一下血压，头晕心慌就停下来。
- 夏天出汗多要注意补水量，不要把允许喝的水一次喝完。
- 有严重贫血、心衰、近期胸痛的患者，运动前先咨询医生。

## 这些情况要停止运动并告诉护士

- 胸闷、胸痛、心慌、明显气短。
- 头晕、眼前发黑、出冷汗。
- 内瘘部位疼痛或震颤减弱。
