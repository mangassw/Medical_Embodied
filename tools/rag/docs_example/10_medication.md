# 透析患者吃药要注意什么

## 为什么用药要特别小心

- 很多药要靠肾脏排出，透析患者体内代谢和普通人不同。
- 有些药会被透析清除，服药时间需要和透析错开。
- 自行加药、减药、停药都可能带来风险。

## 常用药服用要点

- 降压药：按医嘱时间服用，透析前是否停用一定要问医生。
- 降磷药：随餐嚼服，与饭一起才有效，空腹吃没用。
- 铁剂：不要和降磷药同时吃，间隔开更利于吸收。
- 促红素、维生素 D 类药物：按透析安排，不要漏。

## 一定要避免的事

- 不要自己买止痛药、感冒药、中成药乱吃，部分药物会加重肾损伤。
- 不要相信"排毒""护肾"类保健品。
- 不要因为感觉好就自行停药，尤其是降压药和降磷药。

## 看病和用药的小习惯

- 保留一份完整用药清单，换医院就诊时带上。
- 用分药盒按天分好，避免漏服、重复服。
- 忘记服药时不要一次补双倍剂量，按医嘱处理。
- 出现皮疹、恶心、明显不适，及时报告护士。
