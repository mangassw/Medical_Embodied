# 血压管理：在家怎么量、怎么记

## 为什么血压容易波动

- 透析患者血压受容量、脱水、药物、情绪影响很大。
- 有时透析前高、透析后低，波动本身就会带来风险。
- 规律记录能帮助医生调整降压药和干体重。

## 在家怎么量血压

- 用经过校准的上臂式电子血压计，不要用腕式。
- 量之前静坐 5 分钟，不要刚运动、抽烟、喝咖啡。
- 坐姿背部有支撑，手臂与心脏同高，袖带不要绑在内瘘侧。
- 每次量 2 遍，间隔 1 分钟，取平均值。

## 什么时候量

- 每天早晚各一次，固定时间。
- 透析当天：透析前、透析后各量一次。
- 出现头晕、头痛、心慌时随时量。

## 怎么记

- 记录日期、时间、收缩压、舒张压、脉搏。
- 同时记录当天体重和有无头晕、水肿等不适。
- 复诊时把记录本带给医生。

## 这些情况要告诉护士

- 血压持续偏高，伴头痛、视物模糊。
- 血压偏低，伴头晕、眼前发黑、乏力。
- 透析前后血压差别特别大。
- 不要自己加减降压药，调整必须由医生决定。
