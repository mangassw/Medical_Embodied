# 什么时候必须马上叫护士：急症清单

## 必须立即呼叫护士的情况

- 胸痛、胸闷、压迫感，或疼痛放射到手臂、下巴。
- 呼吸困难、喘不上气、平躺就憋气、夜间被憋醒。
- 意识改变：突然糊涂、嗜睡叫不醒、说话含糊、肢体无力。
- 内瘘震颤突然消失，或穿刺点出血按压止不住、迅速肿起大血包。
- 明显心慌、心跳很快或很慢、脉搏不规律。
- 剧烈头痛、视物模糊、抽搐。
- 高热伴寒战、血压明显异常且伴不适。
- 严重恶心呕吐、剧烈腹痛、黑便或呕血。

## 可以稍后告诉护士的情况

- 轻微皮肤瘙痒、轻度便秘、睡眠不好。
- 一般性的饮食咨询、用药时间疑问。
- 透析后轻度乏力，休息后能缓解。

## 出现急症时怎么做

- 先按呼叫器，说清楚"哪里不舒服、从什么时候开始"。
- 不要自己下床走动去找人，避免跌倒或加重病情。
- 不要自行服药、喝水或离开透析区。
- 如果身边有人，请对方帮忙呼叫工作人员，并留在原地等待。
