# 饮水与容量控制：两次透析之间怎么喝水

## 为什么透析患者要控制饮水

- 两次透析之间，喝进去的水大部分会留在体内。
- 水多了会加重心脏负担，引起血压升高、下肢水肿、胸闷气短。
- 长期容量过多还可能影响心功能，所以控水是每天都要做的功课。

## 每天能喝多少水

- 一个常用参考是：两次透析之间体重增长不超过干体重的 3%–5%。
- 具体目标要听从你的医生，因为每个人的干体重和心功能不一样。
- 把允许喝的水量分到一天里，用带刻度的水杯，喝一口记一口。
- 汤、粥、水果、冰淇淋里都含水，也要算进去。

## 口渴了怎么办

- 少吃盐、咸菜和酱料，盐吃多了更容易口渴。
- 可以含一小块冰块、嚼无糖口香糖，或用柠檬片润口。
- 用凉水漱口、勤刷牙，也能减轻口渴感。
- 不要用大量饮料来解渴。

## 每天称体重

- 每天固定时间、同样衣着、排空大小便后称体重并记录。
- 体重突然增加或减少，都要告诉护士。

## 这些情况要马上告诉护士

- 短时间内体重增长明显超过平时。
- 出现下肢水肿、平躺时气短、夜间憋醒。
- 这时不要自己多吃利尿药，也不要大量喝水“冲一冲”。
