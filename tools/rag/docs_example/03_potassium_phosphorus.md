# 钾和磷：透析患者最需要盯紧的两个指标

## 为什么钾高很危险

- 钾主要靠肾脏排出，透析患者排钾能力差。
- 血钾过高会影响心跳，严重时可能出现心跳骤停，这是急症。
- 高钾常常没有明显感觉，所以定期抽血很重要。

## 高钾的常见表现

- 手脚发麻、四肢无力、心慌、心跳不规律。
- 一旦出现明显心慌、胸闷、乏力，要立即告诉护士，不要等。

## 高钾食物要注意

- 香蕉、橙子、猕猴桃、哈密瓜等水果含钾较高。
- 土豆、山药、菠菜、菌菇、紫菜、坚果含钾也高。
- 蔬菜可以先切小块用热水焯一下再炒，能减少一部分钾。
- 不要喝菜汤、肉汤、果汁，钾都溶在汤里。

## 磷高有什么后果

- 血磷长期偏高会引起皮肤瘙痒、骨痛、血管钙化。
- 高磷食物包括动物内脏、坚果、奶酪、加工食品、可乐类饮料。
- 少吃加工食品和含添加剂的食物，看配料表里有没有"磷酸盐"。

## 要做的两件事

- 按医嘱吃降磷药，随餐嚼服效果才好，不要空腹吃。
- 定期复查血钾血磷，把结果记在本子上。
