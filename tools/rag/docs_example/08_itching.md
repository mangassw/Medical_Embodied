# 皮肤瘙痒难忍：透析患者怎么缓解

## 为什么会痒

- 最常见的原因是血磷偏高、甲状旁腺激素升高。
- 皮肤干燥、透析不充分、过敏也可能引起。
- 瘙痒在夜间和透析后往往更明显。

## 从指标上找原因

- 复查血磷、甲状旁腺激素，按医嘱吃降磷药。
- 降磷药要随餐嚼服，不吃饭时不要吃。
- 透析充分性不够也会痒，需要评估透析剂量。

## 日常护理

- 洗澡水不要太烫，时间不要过长，少用碱性强的肥皂。
- 洗完澡趁皮肤微湿涂抹无香料的保湿霜。
- 穿棉质宽松衣物，避免羊毛、化纤直接接触皮肤。
- 剪短指甲，尽量用按压代替抓挠，避免抓破感染。

## 这些情况要告诉护士

- 瘙痒影响睡眠、抓破皮肤出现渗液或结痂。
- 伴随皮疹、黄疸、明显乏力。
- 皮肤出现大片红疹，可能是过敏，要尽快就医。
