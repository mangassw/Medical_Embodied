# 贫血、促红素和铁剂：为什么总是没力气

## 透析患者为什么会贫血

- 肾脏受损后促红细胞生成素分泌不足。
- 透析过程中会丢失少量红细胞和铁。
- 造血原料（铁、叶酸、维生素 B12）不足也会加重贫血。

## 贫血的常见表现

- 乏力、头晕、面色苍白、活动后心慌气短。
- 注意力不集中、怕冷、睡眠差。
- 贫血越重，心脏负担越大，所以不能忽视。

## 促红素和铁剂的使用

- 促红素通常在透析时皮下或静脉注射，按医嘱规律使用。
- 铁剂分口服和静脉两种，口服铁剂空腹或餐前服用吸收更好，具体听医嘱。
- 打促红素期间要监测血压，血压升高要及时告诉护士。
- 不要自行加量或停药，也不要自行买补血保健品。

## 饮食上能做什么

- 适量吃瘦肉、动物血、蛋黄等含铁食物。
- 补铁的同时注意不要用浓茶、咖啡送服，会影响铁吸收。
- 不要盲目大量补铁，铁过量也有危害。

## 这些情况要告诉护士

- 明显加重的乏力、心慌、活动后气促。
- 黑便、牙龈出血、皮下淤青等出血表现。
- 打促红素后出现明显头痛、血压升高。
