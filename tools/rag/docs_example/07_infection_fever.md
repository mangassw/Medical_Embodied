# 发热、感染：透析患者什么时候必须就医

## 为什么透析患者容易感染

- 透析患者免疫力偏低，加上有内瘘穿刺、导管等侵入性通路。
- 感染后进展可能比普通人快，所以要早发现早处理。

## 常见感染部位

- 血管通路：内瘘穿刺点红、肿、热、痛、有脓液。
- 导管：置管处红肿、渗液、疼痛，或沿导管走行发红。
- 呼吸道：咳嗽、咳痰、咽痛。
- 泌尿道：尿频、尿急、尿痛。

## 发热了怎么办

- 先测体温并记录，注意有没有寒战、乏力、气促。
- 体温明显升高或伴寒战时，要立即联系护士或就医，不要自行吃退烧药掩盖症状。
- 就医时主动告诉医生：我是透析患者，用的是内瘘还是导管。

## 什么情况要立即就医

- 高热伴寒战、意识模糊、呼吸急促。
- 内瘘或导管部位红肿迅速扩大、有脓、剧痛。
- 透析后出现持续发热，尤其是透析当天或次日。

## 日常预防

- 透析前洗净内瘘侧手臂，穿刺点保持干燥清洁。
- 不要自己在家处理穿刺点，不要涂抹不明药膏。
- 注意手卫生，少去人多密闭的场所，流感季节按医嘱接种疫苗。
