# 蛋白质怎么吃：透析患者为什么不能"吃得清淡"

## 为什么要吃够蛋白质

- 透析会带走一部分氨基酸和蛋白质，身体处于消耗状态。
- 蛋白质吃得不够，会出现乏力、消瘦、抵抗力下降、水肿消不掉。
- 所以透析患者不是越清淡越好，而是要吃够优质蛋白。

## 什么是优质蛋白

- 鸡蛋、牛奶、瘦肉、鱼、虾、禽肉属于优质蛋白，吸收利用率高。
- 每天可以有 1 个鸡蛋、1 杯牛奶，加适量瘦肉或鱼。
- 具体吃多少克，按你的体重和营养评估由医生或营养师确定。

## 植物蛋白要不要吃

- 主食里的米面也含蛋白，但质量不如动物蛋白。
- 不建议只靠豆制品补充蛋白，豆类含钾磷较高，要控制量。
- 如果血磷偏高，需要同时注意高磷食物。

## 常见问题

- "吃肉会加重肾负担"——透析后这个说法不适用，透析本身就在替代肾脏工作。
- 吃不下的患者可以少量多餐，把蛋白放在正餐而不是零食。
- 体重持续下降、白蛋白偏低，要主动告诉护士。
