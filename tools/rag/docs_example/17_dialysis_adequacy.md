# 透析充分性：Kt/V 是什么，为什么重要

## 什么是透析充分性

- 指透析把体内代谢废物清除得够不够干净。
- 评估不只看"透了几小时"，还要看实际清除效果。

## Kt/V 是什么

- K 是清除率，t 是透析时间，V 是体内水分容积。
- Kt/V 越高，说明清除的毒素越多。
- 医生会根据抽血结果计算，具体目标值由医生判断，不要自己套数字。

## 影响透析充分性的因素

- 透析时间是否足够、血流量是否达标。
- 血管通路是否通畅，内瘘功能好不好。
- 透析器有没有凝血、管路有没有打折。
- 体重增长过多导致需要脱大量水。

## 患者能做什么

- 按时、足次透析，不要随意缩短时间或请假。
- 保护内瘘，保证血流量。
- 控制两次透析之间的体重增长。
- 配合抽血复查，了解自己的 Kt/V 和尿素清除情况。

## 透析不充分的表现

- 乏力、食欲差、皮肤瘙痒、睡眠差。
- 水肿消不掉、血压难控制。
- 这些表现出现时告诉护士，可能需要评估透析方案。
