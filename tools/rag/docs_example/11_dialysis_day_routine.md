# 透析当天怎么安排：透析前、中、后注意事项

## 透析前

- 按护士通知的时间到达，不要迟到，也不要空腹太久。
- 在家先测体重并记录，方便护士计算脱水量。
- 洗净内瘘侧手臂，穿宽松、袖口方便的衣服。
- 带好常用药、病历本和水杯（按允许量饮水）。
- 如果出现发热、腹泻、胸闷等不适，进透析室先告诉护士。

## 透析中

- 全程平躺或半卧，不要随意大幅度活动穿刺侧手臂。
- 出现头晕、出冷汗、心慌、抽筋、恶心，立即告诉护士，不要忍。
- 可以少量喝水，但不要大口喝。
- 不要自己调节机器或管路。

## 透析后

- 穿刺点按压足够时间，确认不再出血后再离开。
- 起身要慢，先坐一会儿再站起来，防止头晕跌倒。
- 当天不要洗盆浴、不要泡澡，穿刺点保持干燥。
- 回家后注意有无乏力、头晕、穿刺点渗血。

## 当天饮食

- 透析会丢失蛋白和氨基酸，透析后可以适当补充优质蛋白。
- 不要因为"透析把水脱掉了"就大量喝水吃东西。
- 记录透析后的体重和血压，下次带给护士看。
