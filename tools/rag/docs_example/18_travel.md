# 出行和旅行：透析患者怎么安排

## 出行前要准备什么

- 提前联系目的地透析中心，预约透析时间，带上病历和透析记录。
- 让主管医生评估当前状态是否适合出行。
- 备足常用药，随身携带，不要放在托运行李里。
- 准备一份用药清单和疾病信息卡。

## 交通途中注意

- 长时间坐车、坐飞机要定时活动下肢，预防血栓。
- 控水仍是重点，途中不要因为口渴大量喝水。
- 内瘘侧手臂避免受压、提重物，注意保暖。
- 随身带少量允许的饮水和小零食，防止低血糖。

## 旅行中的饮食

- 外食口味重、含盐高，尽量选择清淡菜品。
- 避免火锅、烧烤、腌制品、浓汤。
- 水果仍要控制种类和量，不要因为出门就放开吃。
- 提前了解目的地有没有可透析的医院。

## 这些情况要推迟出行

- 近期有感染、发热、胸痛、明显水肿。
- 内瘘功能不稳定，正在处理通路问题。
- 血压控制很差，或刚调整过透析方案。

## 回来后

- 把旅行期间的体重、血压、不适记录给护士看。
- 如果在外地做过透析，带回透析记录单。
