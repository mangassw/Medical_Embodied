# 透析中头晕、出冷汗：低血压怎么办

## 为什么透析中会低血压

- 透析过程中短时间内脱出较多水分，血管里的血量下降。
- 吃得太饱、透析前吃了降压药、体重增长过多，都会增加风险。
- 老年人和心功能不好的患者更容易发生。

## 低血压的常见表现

- 头晕、眼前发黑、打哈欠、恶心、出冷汗、心慌。
- 面色苍白、说话没力气、想解大便。
- 严重时可能意识模糊甚至晕倒。

## 出现了怎么办

- 立即告诉护士，不要硬撑。
- 护士通常会暂停或减慢脱水，让你平躺、抬高双腿。
- 按护士指导补充少量生理盐水或糖水，不要自己大口喝水。

## 怎么预防

- 两次透析之间控制体重增长，不要超太多。
- 透析前不要吃得太饱，也不要空腹太久。
- 透析前是否停用降压药，一定要问医生，不要自己停药。
- 透析前一晚不要熬夜、不要饮酒。

## 什么情况要立即呼叫护士

- 头晕伴随胸闷、胸痛、呼吸困难。
- 意识不清、说不出话、肢体无力。
- 出冷汗同时心慌明显、心跳很快或很慢。
