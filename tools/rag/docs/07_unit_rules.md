# 血液净化中心规章制度

1. 血透室实行相对隔离，血透时患者家属不能陪护，为减少交叉感染。
2. 请您遵守本中心的透析安排。病友到血透室的时间：上午班 8:00，下午班 13:30，请您准时，治疗时间未到请在候诊区等待。如有特殊原因需临时改变治疗时间，应提早通知科室医护人员并得到认可。
3. 透析前先刷卡称量体重；若因气候变化而增减衣物者，称重后告知接诊护士或治疗护士及时调整体重。
4. 血液透析是维持生命的一种治疗手段，不能根治尿毒症；在治疗期间出现不适或并发症，请及时告知医护人员。若在家里遇到紧急情况，可及时向本院医生、护士电话咨询 0571-86932991 / 0571-86918601，或及时到我院急诊室就医。
