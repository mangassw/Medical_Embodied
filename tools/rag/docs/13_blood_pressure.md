# 血压管理与理想血压

## 理想血压目标

- 透析前最好控制在 140/90 毫米汞柱以下。
- 透析后 130/80 毫米汞柱以下。

## 用药与血压记录

- 应遵医嘱服用降压药物，每日测量记录血压的变化供医生参考，根据医生处方服药。
- 为防止血透过程中发生低血压，高血压患者根据血压情况遵医嘱透前减量或停服一次降压药。

## 为什么血压要盯紧

- 血压过高增加心脑血管风险，血压过低会造成透析中不适、内瘘血流缓慢。
- 透析期间的容量控制（体重增长）与血压密切相关，控水是血压管理的一部分。
