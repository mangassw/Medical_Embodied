# 中医适宜技术（耳部）：耳尖放血、耳部刮痧、耳穴压豆

## 耳尖放血

耳尖放血是用特定工具快速点刺耳尖处，并于穴位周围轻轻挤压，使其出血的一种技术，具有祛瘀通络、调节脏腑功能等效果。

- 应用于肾性高血压及透中高血压效果较好，即时与远期疗效皆明显。
- 还可用于麦粒肿、发热、头痛、失眠、咽喉肿痛等。

## 耳部刮痧

刮痧疗法能够开腠理、通经络、调脏腑、平衡阴阳。"耳为宗脉之所聚，十二经脉皆通于耳"，从中医全息理论的角度而言，耳朵是一个相对独立的全息元，是人体的缩影。

- 耳部刮痧能够起到调节脏腑经络、推动气血运行、改善失眠症状的作用。
- 可以缓解血液透析患者失眠、便秘、腹胀、焦虑等症状。

## 耳穴压豆

耳穴压豆技术是使用大小合适的圆形物质贴压在耳穴上，持续地对耳穴进行刺激而达到治疗疾病的一种方法，具有调节神经平衡、镇静止痛、疏通经络、调和气血、补肾健脾等诸多功能。

- 适用于：慢性肾脏病所致的水肿、高血压、失眠、焦虑、便秘、腹泻等患者。
