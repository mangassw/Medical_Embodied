# 首次透析要注意什么

## 一、透析前

1. 放松心情，消除恐惧，进入透析室须先称体重、测血压、脉搏等，以便医生根据生命体征情况实施治疗方案。
2. 透析室不允许家属或陪客进入，除危重病人及不能自理的患者酌情可留一个家属。
3. 带好透析需要的物品：水杯、纸巾、医疗卡、透析卡、小点心、止血带等。

## 二、透析中

1. 刚开始透析时采用多次短时透析，逐渐过渡：第一次不超过 2 小时，第二次 3 小时，以后逐渐增加到 4 小时，经 1～2 周诱导，可进入规律透析（每周 3 次为宜）。
2. 对初次透析的病人应缓慢加大血流量。影响血流量的因素包括患者精神因素、过度紧张导致血管痉挛、血管条件等，需逐渐适应，减少综合反应。
3. 每隔 30—60 分钟测量一次血压，以密切观察病情变化。如有恶心、呕吐、头晕或头痛、抽筋、胸闷、胸痛、冒冷汗、皮肤痒、腹痛、背痛等，及时告诉医务人员，以尽快给予处理。

## 三、透析后

1. 透析结束后须测血压，如血压正常，平躺数分钟、坐数分钟后缓慢起床，防止发生体位性低血压。
2. 称体重，透析后称体重时穿的衣服必须和透析前一致，并约定下次透析时间。
3. 掌握松绷带时间。如在路途中有渗血情况，应立即按压穿刺点，以不出血且可以摸到血管震颤为宜。
4. 透析后当天不能洗澡，24 小时后方可撕去创可贴，也可以在内瘘周围涂抹一些软化血管和疤痕的药（如喜疗妥等）。
