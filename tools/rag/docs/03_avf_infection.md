# 动静脉内瘘感染的防治

动静脉内瘘感染的防治非常重要，需要患者和医务工作者共同努力，维护好自己的血管通路，延长其寿命。主要有以下措施：

1. 注意个人卫生：勤洗澡、勤换内衣、勤洗手、不留长指甲，保持皮肤清洁；治疗前必须清洗内瘘侧肢体；平日可以用一些中性油脂软膏保护动静脉瘘侧皮肤，以免发生皲裂。
2. 预防动静脉内瘘周围的皮肤感染，避免搔痒抓伤，避免外伤。
3. 穿刺操作要严格按照无菌操作要求，避免反复试穿。
4. 透析结束时压迫止血也要注意无菌操作，用无菌敷料覆盖，次日去掉或保留到下次透析。
5. 如需要热敷或冷敷时，不宜用湿毛巾直接敷于针眼处。
6. 游泳或淋浴最好在下次透析前一日进行，或在穿刺部位贴防水胶布。
7. 随时观察动静脉内瘘状况，发现穿刺针眼红肿、附近有红疹或疑似感染灶，应及时用碘伏消毒并与医护人员沟通。
8. 如发生感染应固定内瘘肢体并及时就诊，禁止再穿刺感染部位。
9. 有脓肿形成时，可进行切开引流、应用抗感染治疗；严重者或破溃大出血，需结扎动静脉内瘘，重新建立血管通路。
10. 注意增加营养、增强抵抗力，提高身体抗病能力。
