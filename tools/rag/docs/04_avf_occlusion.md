# 内瘘患者如何预防闭塞


动静脉内瘘闭塞就是病人常说的"瘘堵了"，对患者来说是很痛苦的事情。应了解哪些原因会造成动静脉内瘘的闭塞。

## 引起内瘘闭塞的常见原因

1. 最为常见的原因是治疗后穿刺点压迫止血时间过长、压力过大，使动静脉内瘘中血流不畅造成内瘘凝血。
2. 透析治疗中脱水过多致使患者血容量下降，引起低血压，使患者动静脉内瘘中血流缓慢形成凝血。
3. 感染、反复穿刺造成血管损伤后，血管内皮增生形成狭窄，使血流缓慢形成闭塞等。

## 我们应该如何做

1. 穿刺如不慎刺破血管或血透时针头滑出造成局部出血，早期可局部冰敷，24 小时后可热敷或 50% 硫酸镁湿敷。
2. 睡觉避免内瘘侧肢体受压时间过长；平时内瘘侧肢体勿长时间上举及用力。
3. 血管条件不理想的肾友，每次血透后可用"喜疗妥"涂于患处，范围 3—5 cm，并轻轻按摩数次，热敷每日 3 次、每次 15—30 分钟，并适当手部运动，上下按摩内瘘肢体，以利血管扩张。
4. 居家可用红外线理疗灯照局部：内瘘处血管先涂抹喜辽妥软膏，然后再用红外线照射，一天 2—3 次。
