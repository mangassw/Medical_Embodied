# 中医适宜技术（体部）：艾灸、火龙罐、穴位贴敷、平衡火罐、中药熏蒸、督脉灸

## 艾灸

艾灸具有温经散寒、疏通经络、扶正祛邪的作用。可以促进微循环和组织深部的血流灌注，缓解功能障碍，使人体免疫系统的内环境得到重建、恢复平衡及稳定，以光热激发经络之气，提高机体抗病能力。

- 应用于血液透析患者中，可以防治腹胀、食欲不振、低血压、不安腿、乏力、颈肩腰腿痛等。

## 火龙罐综合灸

火龙罐综合灸结合了"艾灸、按摩、刮痧、走罐、点穴"等多项特色诊疗技术，结合揉、碾、推、按、点、摇、闪、震、熨、烫十种手法，同时具备"温、通、调、补"四大功效。

- 通过在特制的火龙罐内点燃艾绒，产生温热和负压效应，从而达到温通经络、活血化瘀、祛风散寒、调节气血、增强免疫力等功效。
- 督脉为人体阳脉之海，前后与任脉、冲脉相通，温灸、温推督脉可疏通阳经气血，促进全身气血运行，激发脏腑气化的功能；足太阳膀胱经为六经之首，统摄诸阳，在十二经脉中阳气最盛；背俞穴为脏腑之气汇聚之处，对脏腑气血有着重要的调节作用。
- 适用于：慢性肾功能不全、腰膝酸软、倦怠乏力、便秘等患者。

## 穴位贴敷

穴位贴敷是以中医经络学说为理论依据，应用中草药配制成丸、散、膏等不同剂型，直接贴敷于相应的穴位或患处（阿是穴），通过药物对穴位的刺激和药理作用，达到调整机体和治疗目的的方法。

- 涌泉穴是足少阴肾经的首穴，是人体长寿大穴，具有固本培元、延年益寿、养生保健的功效。
- 神阙穴是人体任脉上的要穴，具有温通元阳、复苏固脱、调和脾胃、益气养血、提高免疫力、调节脏腑功能、延缓衰老的功效。
- 适用于：慢性肾脏病所致的血压升高、眩晕、失眠、夜间盗汗、便秘等患者。如：吴茱萸贴敷涌泉穴稳定血压、助眠安神；五倍子贴敷神阙穴收敛止汗；生大黄贴敷神阙穴通腑泻下；肾虚膏贴敷肾俞、三阴交、复溜、太溪、照海穴补肾益气。

## 平衡火罐

平衡火罐是拔罐疗法的一种，以阴阳学说为基础、以神经传导学说为途径、以自身平衡为核心，运用不同的拔罐手法作用于人体的一种中医适宜技术。

- 此法将推拿、拔罐、刮痧等技术有机结合，运用闪、揉、走、抖、留等特殊手法，叠加火的温热效应及火罐的负压、刮拭作用，达到疏通心肾、化瘀祛湿、温经理气、平衡阴阳的功效。
- 适用于：慢性肾功能不全、失眠、颈椎病、腰背酸痛、腹泻、肥胖、围手术期综合征等患者。

## 中药全身熏蒸

中药熏蒸是一种以热力和药力为治疗因子的综合疗法，具有行气活血、消肿通络、疏风止痒的功效。

- 人体皮肤是人体最大的器官，药液蒸汽通过皮肤渗透、转运、吸收，排除皮肤毒素，缓解患者肢体肿胀、皮肤瘙痒的症状。
- 适用于：慢性肾脏病顽固性瘙痒、全身或局部水肿的患者。

## 督脉灸

督脉灸也称为"长蛇灸""铺灸"，是指将艾绒铺于人体督脉（背部正中线）上施灸的一种方法，集督脉、艾灸、药物于一体。其施灸部位以督脉为中心线，同时覆盖督脉两侧的夹脊穴和部分足太阳膀胱经，具有温通气血、平衡阴阳、抵御病邪、调整虚实的功效。

- 适用于：督脉诸证和慢性虚寒性疾病患者，最适用于阳虚体质患者。如：慢性肾脏病脾肾阳虚，出现体寒肢冷、神疲乏力、腰膝酸软等症状患者，以及失眠、慢性腹泻等患者。
