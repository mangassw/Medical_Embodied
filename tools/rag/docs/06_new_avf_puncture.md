# 新瘘穿刺启用宣教


1. 新瘘启用前需要签署新瘘启用告知书。
2. 穿刺前清洗手臂；特别怕疼的可以涂抹利多卡因凝胶。
3. 穿刺过程中配合护士，不随意抽动手臂。
4. 透析过程内瘘侧手臂、肘关节禁止屈伸，手指可以屈伸。
5. 拔针时正确按压针眼：拇指法按压，拇指朝向进针方向，力度按压血管 1/2，指腹下感觉到血管搏动为妥。
6. 下机拔针时，新瘘一般按压止血成功后再绑止血带。
7. 下机离床时，勿用内瘘侧手臂支撑身体。
8. 穿刺处针眼（穿刺点）24 小时保持干燥；如遇渗血等，需按压至不出血。家中可以自备消毒棉签，由中心向四周消毒后更换敷贴。
