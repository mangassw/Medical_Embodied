# 内瘘患者透析后注意事项


1. 保持内瘘侧肢体皮肤清洁、干燥。
2. 透析后 24 小时内不要清洗穿刺部位（患者常说的"针眼""针口"就是穿刺点，"沾水""洗澡"指能否接触水）；透析后当天不能洗澡，24 小时后可撕去创可贴。如不慎污染或浸湿内瘘皮肤穿刺点，应立即用 75% 的酒精或 PVP 碘棉球消毒；内瘘局部出现红、肿、热、痛要及时通知医生。
3. 内瘘侧肢体不宜负重，禁测血压、抽血、输液，禁戴手表、手镯或其他饰物，不穿紧身、窄口上衣，不宜侧卧于内瘘侧肢体睡眠，保持内瘘血流通畅。
4. 养成早、中、晚检查内瘘是否通畅的习惯。具体方法：将 2～3 个手指指腹放于内瘘吻合口处感觉血管震颤，或者用对侧耳朵听血管杂音；如触摸感觉不明显，可用听诊器听诊，听到沙沙音表示动静脉瘘管功能正常。若以上现象逐渐减弱或消失应立即就医。
5. 引起内瘘闭塞常见原因：透析结束后压迫时间过久、力度过重；脱水过多、过快造成低血压；高凝病人自发性血栓形成；血管解剖因素局部狭窄；腹泻、大量出汗；肢体温度过低、冷敷方法不当或时间过长。出现上述状况时应密切观察内瘘震颤与杂音情况。
6. 透析结束后按压止血最好用手指压迫止血，绷带止血力度适中不可压迫过久，避免内瘘堵塞。
7. 内瘘热敷及按摩要点：
   - 透析 24 小时后再热敷，以免穿刺点出血或感染。
   - 热敷时注意水温勿太高，以防烫伤，温度不超过 40℃ 为原则。
   - 热敷面积应限于瘘管处及血管延伸走向部位，避免肢体全部浸泡在水中。
   - 有条件可使用非热康谱仪照射。
   - 热敷和按摩可以同时做，每次 15 分钟，每天 3～4 次。按摩前先在沿血管走向的皮肤上涂抹"喜疗妥"药膏，然后在血管上方用拇指作环状加压按摩，按摩时不能损伤皮肤。
8. 定期进行内瘘血管流量、血管壁彩色超声等检查，建议至少每 3 个月检测 1 次。
