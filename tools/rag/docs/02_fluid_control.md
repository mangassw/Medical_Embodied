# 血液透析患者如何控水（水平衡管理）

## 为什么必须管理水平衡

透析肾友的水平衡是指液体摄入量与清除量保持平衡。如果体内液体过多，可导致心脏负担加重，容易发生心衰；而过度脱水或利尿则会导致血容量不足，导致血压下降，甚至诱发其他严重后果。所以日常管理好水平衡非常重要。

## 每天该喝多少水

这与透析次数有密切关系：

| 透析次数 | 全天水分摄入量 |
| --- | --- |
| 每周 3 次 | 前一天尿量 + 500 ml |
| 每周 2 次 | 前一天尿量 + 300 ml |
| 每周 1 次 | 前一天尿量 + 100 ml |

## 我们的控水原则

- 透析期间体重控制在理想体重的 3%–5%。
- 举例：如果干体重为 60 kg，透析间期的体重增长不超过 60 × 5% = 3 kg。
